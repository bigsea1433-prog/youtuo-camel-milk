# 优驼企业官网

预览地址：http://59.110.49.115:8080/

Next.js 15 + React 19 + TypeScript + Tailwind 4 + SQLite。服务器 Node.js 24，Nginx 反向代理，systemd 常驻服务。当前为内容预览版，禁止搜索收录。

## 页面与内容

首页、关于优驼、牧场与品质、产品中心、品牌动态、联系我们及独立内容详情。内容依据客户提供的企业介绍整理；照片、产品名称规格及联系方式未提供，保留占位。认证、专利数量、销量、工厂进度等需最终核验，不从其他企业网站直接复制事实。

后台支持首页与企业文案修改、产品与资讯的新增、草稿、发布、编辑、删除。当前图片仍由开发时替换，未提供图片上传界面。

## 后台

公网 /admin 返回403，避免HTTP传输密码。通过本机终端建立加密通道：

```
ssh -N -L 127.0.0.1:8081:127.0.0.1:3001 aowang@59.110.49.115
```

保持终端开启，打开 http://localhost:8081/admin 。管理员独立随机密码保存在服务器 `/home/aowang/youtuo-admin-password.txt`，仅 aowang 可读取。服务器SSH密码与后台密码不同。

## 运维

- 源码：服务器 `/home/aowang/youtuo`
- 数据：`/var/lib/youtuo/content.sqlite`
- 环境配置：`/etc/youtuo.env`，不进入Git
- 服务：`sudo systemctl status youtuo` / `sudo systemctl restart youtuo`
- 日志：`sudo journalctl -u youtuo -n 100`
- 每天03:23备份SQLite，保留最近14份，位于 `/var/backups/youtuo`
- 每5分钟更新当天普通浏览器/疑似爬虫请求统计，来源Nginx日志；User-Agent分类不能证明真人身份。
- 访问日志轮转保留14份，IP仅用于每日摘要去重，原始Nginx日志仍含来源IP。

正式域名、备案、HTTPS、搜索收录开关及最终客户信息需在正式发布时配置。8080为预览入口。
