## 内容管理

企业与页面资料按企业介绍、页面文案、官网图片、联系方式与备案、社交媒体与店铺分组。支持先保存草稿、预览字段与图片，再发布。首页、牧场、工厂、研发、公益及二维码图片可从素材库选择替换。

企业高层独立管理姓名、职务、简介、照片和排序。产品具有规格、配料、营养表、食用方式、储存条件、主图和补充图片字段。资质与检测支持编号、颁发机构、主体、日期、有效期、关联产品与原件图片。博客和公益支持分类、正文、封面、活动图片、草稿及发布。

图片支持JPG、PNG、WebP，单张不超过5MB；不接收SVG、可执行文件或PDF。证书目前使用原件图片展示。

## 账号权限

超级管理员管理全部内容、账号与角色。企业管理员维护与发布内容、查看操作记录及恢复版本，不能管理账号。编辑可上传素材和准备草稿，不可发布或删除内容；修改已发布文章/产品应先复制为草稿交管理员处理。

账号初始信息另行私下交付，不进入本仓库。密码使用scrypt加盐保存，登录会话8小时；停用、改密、重置或调整账号会撤销其会话。HTTPS会话Cookie设置Secure、HttpOnly及SameSite。

## 历史与恢复

保存修改和删除前保留版本，管理员可从历史恢复。文章、产品、人物与证书恢复后先成为草稿；企业资料恢复直接更新公开设置。删除采用软删除避免ID复用；不自动清理历史记录和被引用图片。正文仅渲染有限Markdown，不注入HTML，链接限制为站内路径或HTTPS。

对于已发布内容，直接保存会更新页面；若要保留现有页面并准备新稿，先复制为草稿。副本发布不会自动替换旧文，应由管理员核对后撤下旧文。

## 运行维护

源码：`/home/aowang/youtuo-v3`；数据库：`/var/lib/youtuo/content.sqlite`；上传文件：`/var/lib/youtuo/uploads`；环境配置：`/etc/youtuo.env`（不入Git）。

必要环境变量：`DATA_DIR`、`ADMIN_PASSWORD_HASH`（首次引导总管理员）、`COOKIE_SECURE=true`。首次启动如无总管理员，用环境中的原管理员密码摘要引导owner账号；首次成功登录迁移为scrypt。后续账号由数据库管理，不重置已有密码。

生产构建使用Node.js 24执行`npm ci`及`npm run build`，成功后重启`youtuo.service`。SQLite数据库与上传文件独立于源码。不要在日常部署时重复运行资料初始化脚本覆盖客户编辑。

每天备份数据库及上传文件，保留14份，路径`/var/backups/youtuo`。同机备份不能替代异地备份。访问统计依据Nginx日志推测浏览器和爬虫，不代表已验证真人。

HTTPS使用IP证书；有效期较短，由`youtuo-cert-renew.timer`每日检查两次，续期后重载Nginx。配置在`/etc/nginx/conf.d/youtuo-client.conf`；证书在`/etc/letsencrypt/live/youtuo-ip`。可检查`systemctl status youtuo-cert-renew.timer`和续期服务日志。正式域名、备案和收录策略尚未切换；预览站保持不收录。

## 验证与限制

已通过生产构建/类型检查，以及真实后台HTTP流程：独立账号、角色校验、草稿隔离、预览、产品字段发布、活动图片、资质关联、删除恢复、企业资料草稿与发布、改密、停用及客户HTTPS登录。约3MB的有效PNG经过HTTPS上传成功。测试账号和内容已清理。

浏览器自动检查连接超时，本轮未完成逐屏视觉及真实手机验收。后台提供固定模板的内容维护，不是任意拖拽页面设计器。证书、产品包装与营养表、企业照片等需客户提供真实资料。
